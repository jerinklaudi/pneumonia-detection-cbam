Pneumonia project recovery package

contains the figures embedded in the notebook and the captured textual experiment outputs.

- outputs/notebook_text_outputs.txt: captured text output from executed cells
- Pneumonia_Project_Consolidated_ReportReady.ipynb: uploaded executed notebook

Important: CSV files and trained checkpoints are listed by the notebook's final cell as outputs
created in its former runtime, but their actual file contents were not embedded in the notebook.
